# XR Project Proposal: Chinese Character to Element – An Interactive XR Experience
### 1. Project Overview
The aim of this project is to develop an interactive Extended Reality (XR) game that combines Chinese calligraphy, character recognition, and elemental visual effects.
Players will be able to write Chinese characters in 3D space using their hands or VR controllers. The system will recognise the characters and transform them into corresponding natural elements within the virtual environment.
For example, when a player writes the Chinese character "火" (Fire), a fire effect will appear in front of them. When they write "水" (Water), a stream of water will emerge.
The main idea is to create an immersive experience where players can interact with the virtual world through Chinese writing.
